# 外屏安全区

## 责任与范围

`SafeAreaManager` 是安全区策略唯一入口。自动模式复用 `CoverWindowInsets` 的完整窗口实测／最大窗口回退；手动模式使用 `Prefs` 当前方向的冻结自动基准与四边有符号像素偏移，允许小于系统报告的边衬，不能再与旧自动值取最大值。原始系统值保留用于诊断。真实缺口独立保留，不镜像、不按机型硬编码，也不改变系统手势优先级。

`CoverService` 负责显示器和窗口生命周期，`DockGeometry` 负责摆放算法，`SafeAreaGeometry` 负责区域和缺口约束。正文、状态栏、快捷栏、白条、任务、启动器、详情、编辑和原生卡片内容使用统一输出。Activity 将显示器坐标转换为窗口局部边距；主屏设置仍使用主屏窗口边衬。键盘临时避让保留，系统页面及卡片宿主的位置仍由系统控制。原始窗口及背景采样保留屏幕范围，页面可见外框和实际触摸目标服从各自安全范围。

安全区是固定的页面边界。自动、手动及校准中的四个方向，快捷栏绘制和整个触摸窗口都只能使用安全区之外、真实缺口之外的可用区段；不得把快捷栏移入正文，也不得再从安全区扣掉一列或一行。优先保留合法的原位置；原位置不可用时在外侧区段选择并适当压紧快捷栏自身，不能镜像真实缺口。自动模式开启导航避让时，所有候选方向还须保留系统边衬和额外间距。外侧无可用空间时暂不显示快捷栏，诊断保留原因；可缩小安全区，或在自动模式关闭导航避让后重新定位。空快捷栏不能参与白条和正文扣边。白条、状态栏与临时键盘仍按各自正文预留规则处理。

## 设置与校准

入口是“快捷栏与手势”根菜单第一项“外屏安全区”，支持搜索。四个方向以紧凑单行选择，分别保存模式和参数。大字号空间不足时该行可横向滚动，不换行。选择方向只查看配置；“开始调整”提示临时旋转至目标方向，方向相同时提示临时锁定，用户继续后才操作所选外屏。需助手运行、外屏点亮及 Shizuku 连接，不自动授权。

`SafeAreaCalibration` 是服务内单一会话，Activity 旋转重建后重绑。先读取并保存系统 user-rotation/fixed-to-user-rotation，再临时锁定；确认实际方向与布局后才建立草稿。四边偏移用滑条、1px 加减和数字输入编辑；0 是保存的自动基准，负数向外扩展、正数向内收缩，超出屏幕的部分裁到物理边缘，输入和滑条范围一致；滑条拖动更新数值，松手后在外屏试用，只有“保存”写入偏好。取消恢复原安全区。后台、息屏、换屏、尺寸变化、断连及服务释放取消草稿；迟到命令校验会话代次和目标身份。

结束时恢复原系统旋转；原工具自动旋转在校准期间暂停，恢复后继续。恢复失败保留本机信息，显示原因及重试入口，重新连接时可恢复同一所选外屏，不对主屏或替换后的外屏执行旧请求。恢复完成前暂停工具自动旋转。

切回自动保留手动参数，再切回手动恢复原值。“用当前自动值填入”只改变草稿。“重置本方向”清除该方向配置，“全部重置”一次清除四个方向并恢复自动。首次手动以自动边衬为起点；边界只确定页面，缺口旁的快捷栏区段独立位于页面之外，切换手动本身不能把它推入正文。

## 辅助线与数据

独立开关“显示安全区辅助线”决定平时显示状态。校准时自动显示，结束恢复开关的选择。`SafeAreaGuideView` 只描最终页面边界，自动和手动都不将快捷栏区段合并进描边；真实缺口扣除，当前调整边高亮。窗口不接收触摸或焦点，只在所选可用外屏挂载，随窗口释放移除，不后台轮询或抓屏。

`safe_area_0..3` 保存模式、四边实际边衬、可选 `reference` 自动基准、布局宽高和本机目标身份；103 的无基准旧配置保留实际位置，再次校准时建立基准；`safe_area_guides` 保存描边开关，均排除在跨设备配置及布局导入导出外。尺寸／目标不匹配时保留参数并采用自动模式，提示重新校准。`safe_area_rotation_restore` 只记录未完成校准的旋转恢复信息，成功恢复后删除，不导出。

既有诊断增加模式、自动及最终边衬、手动配置、临时校准和辅助线开关，继续记录白条请求、实际窗口和绘制坐标；不上传，历史上限与采样触发不变。

## 验证入口

- `SafeAreaGeometryTest`：参数边界、不同尺寸／目标拒绝、四方向触摸与绘制同步、真实缺口，以及所有停靠/反向设置下快捷栏与页面零交叠、外侧无空间时正文不缩小。
- 模拟器 `safe-area`：根入口、四方向所有白条位置、0/64/96/144px 系统报告、自动／手动／重置、全部布局消费者和描边。手动底边 144→96→66→30→0 检查白条向外移动，避免左侧快捷栏重复抬高右侧入口；另以自动/手动、导航避让、正负调整覆盖快捷栏位于页面之外、所有正文消费者保持完整宽度、辅助线不包含快捷栏区段。
- `full-window-insets`、`runtime-safe-area`、`panel-entry` 检查自动及手势回归；真机另查旋转确认与恢复、主屏隔离、辅助线触摸穿透、键盘、服务重连及原生卡片宿主。

模拟器或正常手机通过不能替代 SM-F731N／SM-F741N 异常固件的实际触摸与位置反馈。

## 管理器与宿主契约

统一使用四层边界，不以一个矩形代替所有用途：

1. 原始窗口／取样范围保持实际显示器尺寸，供窗口挂载、截图、玻璃纹理映射及转场使用。
2. 页面边界取自动或手动安全区与真实缺口可用矩形的交集；控制、通知、任务及启动器的圆角、背板、边缘渐隐和模糊过渡共同使用它。
3. 正文边界在页面内再避让状态栏、白条和临时键盘；快捷栏在页面外，不参与正文尺寸扣减。列表、编辑、详情和可操作目标使用此范围。白条预留不能提前移动页面渐变。
4. 局部组件边界使用已分配容器的实际尺寸；按钮、媒体卡片、侧栏、任务预览和列表自己的圆角、阴影与溢出渐隐仍跟随该组件，并受祖先页面裁切。

页面轮廓的静止圆角取所属窗口的系统物理圆角，玻璃与纯黑降级共用管理器计算；安全区相对原始窗口的内缩不表示转场浮起，不能据此改大圆角。仅实际转场位移允许浮起过渡，归位恢复物理半径。`page-corners` 场景按0/90/180/270度检查四类真实挂载页面、完整/内缩边界、玻璃释放与横纵转场。

`Boundary` 明确窗口、页面、正文的嵌套与局部原点。`viewContent` / `mapViewBounds` 将所属卡片或输入宿主的有效范围映射至弹层局部坐标，包括设置缩放、父级偏移及已经扣除的边衬。`DetailSheet` 统一在该范围居中并测量；详情、文件夹、编辑二级层和输入面板不再各自估算屏幕边距。模态遮罩可以覆盖父窗口，但可操作卡片及其局部阴影留在正文范围。应用自有菜单在当前 `InputSurface` 内打开；系统组件和外部应用的系统菜单仍由其宿主管理。

运行时正文单独裁切到内容范围，通知列表的绘制溢出不能覆盖入口预留区；页面拒绝正文以外的新内容触摸，横向换页也检查同一范围。正在进行的手势保留原有取消和交接规则。外接输入焦点绘制、点击及原生卡片输入范围同步约束；滚动列表的屏外候选仍可导航至可见位置。独立 Dock 的页面背板可隐藏，但其局部材质、内容和触摸依然服从所分配范围。

`page-boundaries` 检查四方向和四类页面的外框、边缘像素、正文触摸隔离、详情及输入面板，以及缩放设置／键盘尺寸下的弹层居中；`runtime-safe-area` 使用真实业务布局检查自动／手动边界。

`SafeAreaManager` 是显示器尺寸、物理模式、窗口度量和屏幕位置读取的唯一入口。`Snapshot` 是绑定显示器身份、方向、原始宽高、密度及修订号的不可变结果；自动／手动共同输出有效边衬及真实缺口。`contents` 给出正文、入口、状态栏、启动器、任务和组件区域；`clockHandle` 给出收起箭头位置。现有 `DockGeometry` 与 `WidgetSafeArea` 作为纯计算模块保留。

- 快捷栏、白条、收起箭头、状态栏与控制／通知／任务／启动器卡片由 `CoverService` 使用管理器结果挂载。绘制和触摸共享布局，子控件使用父容器实际测量尺寸。
- 设置、原生卡片编辑和系统输出 Activity 使用 `activityInsets`；预览使用 `contentBounds`。有同一有效快照的运行时布局时，Activity 使用已避让白条及状态栏的正文边界，不能只用页面外框；无有效服务时使用当前显示器安全区。根容器只转换并扣除一次，附着时订阅安全区变更、卸载时释放，不增加轮询。
- 三星 Activity 的兼容尺寸可能是854×822而悬浮层是748×720。转换使用实际最大窗口范围与原点，不能用资源 density 比值；重建重新转换，键盘只影响临时局部区域。没有服务快照时，从 application 的所选 Display 上下文取得同坐标来源的信息，不使用 Activity 的兼容 Display 与未缩放缺口混合计算。
- 原生卡片通过 `nativeContent` 和 `nativeFrame`，保留原始画布作为映射分母，再按真实宿主位置适配安全区，避免双重扣边；原生输入层跟随该宿主。
- `PanelGlassSession` 和截图使用 `rawDisplaySize`，硬件身份及外部应用显示策略使用 `physicalSize`；手动安全区不改变硬件分辨率或第三方应用布局。
- `screenLocation` 表示实际宿主坐标，用于诊断、MotionEvent 原始位置和 View 间相对偏移；不能再次扣安全区。
- 控制编辑、媒体详情、文件夹、拖拽、输入焦点和分页通过已分配容器范围适配。所有 View 的 `getWidth/getHeight` 继续表示局部测量值。

`tools/project/check.mjs` 检查业务源码不得直接读取屏幕尺寸、窗口度量、物理模式尺寸及屏幕位置；管理器以外的旁路视为检查失败。诊断同时保留安全区修订号、原始/有效边衬、实际白条位置，并追加设置窗口最大范围、当前范围和局部可用范围。
