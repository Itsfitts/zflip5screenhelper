# 使用与权限

安装包构建和旧版迁移见[开发说明](development.md)，配置与权限由用户在手机上操作。

在“关于与更新日志”手动检查新版、下载并校验完整 APK，点击安装后由系统确认。更新地址从 `app-config.json` 读取，不后台轮询或自动下载。服务器发布和构建配套见[在线更新](online-update.md)。

1. 安装正式 APK 或自行构建的调试 APK，打开应用设置。
2. 选择要使用的外屏，并按权限页面提示启用无障碍服务等所需权限。
3. 如需特权系统操作，启动 Shizuku 并授权本应用；查看通知和使用小组件时，分别完成对应的系统授权。
4. 根据外屏实际显示效果调整快捷栏、安全区域和应用布局；需要原生卡片时，在三星外屏的卡片管理中添加对应入口。

显示器专属操作只作用于选定外屏，不静默回退主屏；影响内外屏的系统开关会单独说明。项目不自动授权、不绕过锁屏，联网仅用于用户发起的更新检查和下载，不上传通知、配置或设备信息，不增加分析追踪。三星固件、第三方小组件和系统窗口路由的兼容性仍需以物理真机验证为准。

## 快捷栏模式与箭头

通过双白条打开面板后，控制中心向右滑可切到通知中心，通知中心向左滑可切回控制中心。页面跟随手指移动，距离不足或拖回会回弹。通知卡片横滑继续处理该条通知；其他没有横向操作的区域，包括普通按钮、竖向亮度／音量条，可横滑切页。先开始上下滚动或调节时，本次手势保持原操作；编辑和详情中不切页。

“快捷栏与手势 → 按钮与布局”中的“自动回到第一页”默认开启：停止操作5秒后，底部快捷栏回到第一页；触摸、滑动或长按时不会自动跳页。关闭后保留当前页。收起或隐藏时停止计时，重新显示后重新等待5秒。此开关纳入配置及布局备份，旧配置缺少该项时默认开启。

在“快捷栏与手势 → 快捷栏模式与收起”切换“收起展开模式”。关闭为常驻模式；开启后由箭头控制展开和收起。长按任意可见白条是同一个模式开关的快捷方式，不再临时切换按钮显隐。透明白条不接受长按，仍可滑入通知或控制中心。

“按前台应用自动隐藏”是一个功能，“选择自动隐藏的应用”用于配置它的名单。开启后，进入名单中的应用时快捷栏和箭头都隐藏，优先于常驻／收起展开模式；首页是否遵循名单由“首页跟随快捷栏规则”决定。离开后恢复原来的模式和展开状态，双白条保留。关闭后名单不生效。键盘自动避让仍只用于常驻模式。

收起展开模式开启后先收起快捷栏，单击箭头展开，再次单击收回。切换应用、返回桌面、打开和关闭助手面板，以及同一外屏旋转时保持当前展开状态；时钟首页按下方独立开关处理。模式持久保存并纳入配置与布局备份；息屏、切换目标外屏或服务重新启动后保留模式，从收起状态开始。真正锁定时仍全部隐藏。箭头与快捷栏使用同一套几何与动画，每次只显示一个入口；助手面板或启动器打开时暂时移除箭头，关闭后恢复。

收起箭头始终位于原快捷栏位置，沿用快捷栏的缺口及用户导航避让设置，不因进入 App 再额外向内移动。展开后箭头与快捷栏联动，移到快捷栏内侧，避免挡住按钮。

## 首页与其他页面的箭头

“快捷栏模式与收起”中的“首页跟随快捷栏规则”默认关闭，首页指三星外屏时钟页：关闭时，两种模式每次进入首页都强制收起，保留箭头，点击可临时展开；离开首页恢复其他页面原来的模式和展开状态。开启时，首页同步常驻／收起展开模式及展开状态。“选择自动隐藏的应用”已移除“三星外屏与系统面板”，升级及导入旧配置会清除这条快捷栏隐藏规则，首页不会再因为系统界面名单被隐藏；“三星 One UI 桌面”仍可选择。此开关进入配置及布局备份，旧文件缺少字段时默认关闭。

首页上的收起箭头半透明显示，3秒后淡出，透明后仍可点击；展开时始终可见。收起展开模式在其他页面收起时保持半透明，不自动淡出。离开首页取消旧淡出计时，返回首页恢复延迟淡出；同步规则导致箭头隐藏时也会释放旧计时。三星时钟首页不一定处于系统锁定状态，系统真正锁定时仍全部隐藏，不增加锁屏操作能力。

## 定位开关

“定位”控制整台手机的定位总开关，使用前连接并授权 Shizuku。可在快捷栏编辑、控制中心内编辑和“侧栏常用项”的内置功能中添加；侧栏配置由浮窗应用中心和三星原生启动器卡片共用。新配置的控制中心默认带有定位，已有自定义列表保持原样。

控制中心的开关高亮表示已确认开启，问号表示状态未知，省略号表示正在执行。Wi-Fi、蓝牙、移动数据、勿扰和飞行模式通过 Shizuku 读取并随系统变化刷新；移动数据对应当前数据 SIM 的开关，不代表已经联网。应用磁贴若尚未适配状态回读，会保持问号，灰色不能当作已关闭；点击结果以原应用为准。旋转按钮分别显示“工具自动旋转”“旋转锁定”“系统旋转”或“旋转状态未知”，不会把交回系统当成锁定。

如果改装设备横屏时的快捷栏位置与正常手机相反，在“旋转方向”页面或控制中心旋转详情里开启“左右反向”。默认关闭，只保存在这台手机；开启后仅在90°／270°时把快捷栏移到对角位置，双白条继续使用各方向原来保存的位置，0°和180°布局不变。画面朝向、角度按钮、自动旋转和应用方向规则保持原样，关闭即可恢复原布局。导出或导入配置不会迁移这个设备兼容选项。

默认自动定位时，关闭对应正常布局：系统90°时快捷栏在左上，270°时在右下；开启才对应反向布局：90°在右下，270°在左上。这里的角度以手机系统为准，不使用电脑端投屏窗口的旋转角度。缺口位置继续按设备实际信息避让。

点击切换，控制中心显示实际开关状态；长按控制中心的定位按钮可查看详情或进入系统定位设置。此功能不获取当前位置，也不会修改各应用的定位权限。未连接 Shizuku、系统拒绝或无法确认结果时会显示提示，息屏或锁屏时不能执行。

## 应用显示大小

如果应用在外屏显示成类似平板的布局、字太小，可打开“清晰竖屏（实验）”，再从本工具打开应用。手机保持原来的拿握方向，原应用在竖向区域内显示并可滚动；开启后仍能调整显示大小。关闭开关会保留原大小参数，恢复大小也不会关闭开关。分辨率缩放小于 1 时仍可能变模糊。

进入“应用与小组件 → 应用显示大小”选择应用，或从浮窗启动器的应用操作菜单进入。简单模式提供“更小、较小、默认、较大、更大”，主要通过分辨率缩放调整；高级模式可编辑 DPI 和分辨率缩放系数，点击“应用设置”提交。切换模式不改值，“默认”恢复首次调整前的设置。“打开应用”只在所选外屏打开，不会自动重启。

有些应用（集成了 **AndroidAutoSize**）会按屏幕宽度自行调整界面，单改 DPI 可能看不出变化，优先尝试五档。保存后先从最近任务关闭应用再打开；仍无变化时，可在系统应用信息中手动“强行停止”后重开，后台服务也会停止，无需清除数据。

仍然太小时，可在高级模式将分辨率缩放系数逐步调到 0.9、0.75 或 0.5；小于 1 通常用于放大，会减少同屏内容并降低清晰度。例如 0.5 会让应用绘制画面的宽、高各减半后再放大显示；外屏面板的物理分辨率不变。系数 1 有系统特殊含义，不能直接填写。DPI 并非越小字越大，不要为了放大而盲目降低 DPI。看到输入旁的“未保存”时，系统仍沿用上次成功保存的设置。

需要已连接并授权的 Shizuku，且应用已加入 MultiStar 外屏启动器。未识别到兼容策略时会提示，不自动授权或修改应用名单。设置只留在本机；真实效果需重新打开应用检查。详细范围和恢复说明见 [应用显示大小](app-display-size.md)。

## 启动失败时反馈

可先查看“应用与小组件 → 应用 Dock 与中心 → 兼容性说明”，也可从“问题诊断”进入。页面列出阿田手势后台、原生卡片编辑、系统最近任务和任务预览的已知限制与处理方式。

“系统最近任务”需要 Shizuku 授权，通过三星系统入口请求在所选外屏打开。它不会自动重启三星桌面；固件不支持或请求失败时会提示，可使用“外屏多任务”查看本工具的任务页。

“外屏多任务”同时显示内屏和所选外屏的最近任务。内屏应用名后有小字“(内屏)”，卡片只显示应用图标，不读取内屏任务截图；点击后请求将原任务切到外屏，系统未允许或尚未确认时会保留任务页并提示。系统保留的未挂载任务也会显示图标。上滑关闭和下方 × 会关闭列表内对应的未锁定任务，包含内屏任务；Dock 最近应用区仍只显示所选外屏的应用。系统未提供的任务不会伪造为卡片。

出现卡片或浮窗启动失败后，在同一次运行中打开“设备与权限 → 问题诊断”，点击“刷新日志”再“复制检测结果”，把文本与错误提示发给维护者；不需要连接电脑、先开日志开关或执行 Shizuku 检测。切换省电或其他系统设置后，可留在原诊断页刷新，按日志中的采集时间确认已更新。刷新会清除之前的 Shizuku 补充结果，需要时再单独检测。方便时，先从另一个启动器打开同一个应用作为对照，再刷新复制。记录保留本次进程最近96条技术事件，不含应用名称、通知正文或页面内容，不写入磁盘、不自动上传；重启手机、强行停止或系统回收进程后记录会消失，因此请及时复制。

## 白条位置或底部留白异常时反馈

在外屏复现白条离边、上滑困难或控制中心底部留白后，先拍下完整外屏，再尽快进入“设备与权限 → 问题诊断”，点击“刷新日志”和“复制检测结果”，发送完整文本与照片。不需要连接电脑或点击“通过 Shizuku 检测”。先保留原配置，反馈前不要重启、强行停止、清理应用数据或重新开关无障碍服务。

检测结果包含缺口、导航及强制手势边衬、白条计算位置、请求窗口和布局后的实际绘制位置，并保留最近12次不同位置记录，因此返回设置后仍可查看此前的外屏状态。数据只在本次服务内存中保留；服务重建后会清空，不自动上传。请一并说明发生页面、屏幕方向、是否刚切换应用或解锁，以及从白条上起滑和从屏幕边缘起滑是否有区别。若后续位置恢复正常，可再复制一份并注明“正常对照”。
